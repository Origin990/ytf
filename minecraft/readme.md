## 📦 使用方式

1. **下载整合包**
   - 从官方渠道下载最新版本整合包

2. **安装 Java**
   - 确保已安装合适版本的 Java（推荐 Java 17 或更高）
   - 建议从 [Oracle官网](https://www.oracle.com/java/) 或 [Adoptium](https://adoptium.net/) 下载

3. **启动游戏**
   - 运行整合包自带的启动器
   - 或使用支持第三方整合包的启动器（如 HMCL、PCL 等）

4. **开始冒险**
   - 进入游戏世界，体验极致流畅的游戏乐趣！
